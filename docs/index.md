# Vigil Insurance: Proactive Safety Agent

Welcome to the documentation for the **Proactive Safety Agent** ecosystem. This project demonstrates an autonomous AI team built with the Google Agent Development Kit (ADK) that monitors, triages, and mitigates vehicle safety risks in real-time.

## The Vision

Traditional insurance is reactive. **Vigil Insurance** is proactive. 

Instead of waiting for a claim, our AI agents monitor global recall databases (like NHTSA), identify affected policyholders, and autonomously coordinate solutions—like dispatching a Waymo to their home and booking priority repair slots at local dealerships—before an accident ever happens.

## Key Features

- **Autonomous Detection**: Continuous monitoring of vehicle recall APIs.
- **AI-Driven Triage**: Gemini-powered risk assessment and severity classification.
- **A2A Coordination**: Agent-to-Agent protocols for Waymo dispatches and Dealer bookings.
- **Live Command Center**: A high-fidelity React dashboard providing real-time telemetry of agent activity.
